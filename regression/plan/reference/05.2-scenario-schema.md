# 5.2 Unified scenario schema (`regression/schema/scenario.py`)

> Part of the [regression plan](../README.md). Section numbers (§5.9, §6.U, D12, …) are global across the plan; the README's section map says which file holds each one.


One Pydantic model. `mode` decides which keys are legal. Unknown keys are an error (today the live loader ignores them silently).

| Key | Modes | Meaning |
|---|---|---|
| `id` | all | Derived from path; YAML value must match if present. |
| `case` | all | Required. The case ID from the catalog (`T2-LOOP-07`). Used by the pairing test (5.10) and copied into ledger records (5.9). Python tests use `@pytest.mark.case("...")`. |
| `description`, `tags` | all | Metadata. `tags` are labels for reports and filtering; suite membership is the explicit list in `t4/suites/*.yaml`. `regression/plugin.py` maps `darwin-only` to the `darwin_only` marker and `needs-postgres` to `needs_postgres`. |
| `regression_of` | all | Optional commit SHA / issue / PR link for bug-fix cases (section 10.1). |
| `mode` | — | `scripted` (T2), `replay` (T3a), `live` (T4). |
| `driver` | scripted, replay | `loop` (default), `gateway` (P2-01) or `realtime` (P2-05). |
| `messages` / `sessions` | all | One user message per item; `sessions` = list of message lists, each a fresh session. `session_pause_sec`. |
| `script_partial` | scripted | `true` allows unconsumed script calls (invariant 7, §5.3.2). Default `false`. |
| `invariants_skip` | scripted, replay | List of `{name, reason}`; a reason is required (§5.3.2). |
| `script` | scripted | List of provider calls; each a list of events. Event types: `text`, `thinking`, `tool_call`, `tool_input_delta`, `grounding`, `usage`, `done` (`truncated`), `raise`. |
| `cassette` | replay | Path under `t3/trajectories/`. |
| `executor` | scripted, replay | `recording` (default) or `real`. |
| `tool_results` | scripted (`recording`) | Map `call_id -> envelope` for scripted tool results. |
| `workspace_fixture`, `workspace_overlays` | all | Paths under `regression/fixtures/workspaces/`. Until P4-01 moves them, the `calc_repo`, `calc_repo_green`, `shop_repo` and `overlays` fixtures resolve from `evals/fixtures/coding/` (the loader tries both). `{workspace_subdir}` substitution for live. |
| `config` | all | YAML overrides merged over the base agent config, plus `env:`. Example: `model.context_window: 4000`. |
| `hooks` | scripted, replay | Named hook bundles to register: `verification_gate`, `evidence_guard`, `secret_scanner`, `verifier`, `git_context`, `read_ledger_compaction`, `memory`. Replaces today's hardcoded `gate: true`. |
| `policy` | scripted, replay | Fixture names for `command_allowlist`, `permissions`, `grants`. |
| `memory` | scripted, replay | `index:` lines (today's `memory_index`) or `palace:` seed drawers for `InMemoryPalace`. |
| `history` | scripted, replay | Preloaded rows (for repair, rewrite, compaction cases). |
| `steps` | scripted, replay | Mid-run actions keyed to an event predicate: `cancel`, `steer`, `queue_follow_up`, `promote_follow_up`, `answer_ask_user`, `confirm_tool` (approve/deny/always), `touch_file` (mtime/size change), `advance_clock`, `reload_config`, `disconnect_sse`, `reconnect_sse(last_event_id)` (gateway driver only, P2-01). The realtime driver adds `client_text` and `interrupt` (P2-05). |
| `assertions` | all | Section 5.3. |
| `trials` | live | Default N for T5 when this scenario is in a trial suite. |
