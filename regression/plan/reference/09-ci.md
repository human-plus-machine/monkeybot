# 9. CI and run matrix

> Part of the [regression plan](../README.md). Section numbers (§5.9, §6.U, D12, …) are global across the plan; the README's section map says which file holds each one.


| Job | Trigger | Runs | Secrets | Budget |
|---|---|---|---|---|
| Pre-commit (`pytest` hook) | Every commit touching `src/monkeybot`, `testkit`, `tests`, `regression` | Changed test files, else a collection check of `tests regression` | none | seconds |
| Pre-push (`scripts/ci-local.sh`) | Every `git push` | `pytest tests regression -m "t1 or t2 or t3"` | none | < 5 min |
| `ci.yml` | Today `workflow_dispatch` only; see D2 | Same as pre-push | none | < 10 min |
| `storage-parity` (new, optional; P2-07, waits for D3) | PRs touching `core/persistence/**` or `core/memory/**`; nightly | `tests/contracts/test_storage_parity.py` (plus `-m "needs_postgres or needs_firestore"` under `tests/unit/core/persistence/`) with Postgres service + Firestore emulator | none | < 10 min |
| `cassette-staleness` (new; P3-03, a step in `ci.yml`) | PRs touching any `uv.lock` | `regression/t3/tools/check_staleness.py` | none | < 1 min |
| `live-smoke` | Existing triggers (develop → main, lockfile PRs, push to main, manual) | `regression --live --suite smoke` | `OLLAMA_API_KEY` | 30–45 min |
| `live-trials` (new; P5-03, `live-trials.yml`) | Nightly + manual + PRs into `main` | `python -m regression.t5 --suite <s>` once per T4 suite: `coding_hard`, `drift` (twice: `@verifier-tracker`, `@verifier-judge`), `subagents`, `memory`, `mcp`; compares against `regression/t5/baselines/` | `OLLAMA_API_KEY` | hours |
| monkeyapp `contract` (new, in monkeyapp) | Every monkeyapp PR | Vendored schema validation of the fake gateway and dispatcher | none | < 1 min |

Every job above (except monkeyapp's) runs with the failure ledger on and uploads `test-runs/` as a build artifact, pass or fail, so a CI failure can be triaged with `python -m testkit.failures` after downloading it. `MONKEYBOT_TEST_TRIGGER` is set to the job name.
