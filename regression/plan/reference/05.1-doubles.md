# 5.1 Doubles (`testkit/` and `src/monkeybot/core/testing/`)

> Part of the [regression plan](../README.md). Section numbers (§5.9, §6.U, D12, …) are global across the plan; the README's section map says which file holds each one.


Today the T2 runner imports `FakeProvider`, `FakeHistory`, `RecordingExecutor`, `AllowInspector` from `tests/core/test_loop.py` and `_mem_sub`, `_NoMCP` from `tests/core/test_core_tool_executor.py`, and 45 test files in total (66 import lines) import helpers from sibling test modules the same way. Renaming a test helper breaks unrelated tests. All of these get one supported home:

- `src/monkeybot/core/testing/` only for doubles the running gateway itself must build (the scripted provider behind `MODEL_PROVIDER=fake`, and the existing realtime mocks).
- `testkit/` for everything else. Both `tests/` (tier 1) and `regression/` (tiers 2–5) import from it; existing tier-1 tests switch their cross-module imports to it during Phase 0a, and the duplicated copies (four `FakeHistory`s, several capturing providers) are collapsed into one.

| Double | Where | Requirements |
|---|---|---|
| `ScriptedProvider` | `src/monkeybot/core/testing/mocks_provider.py` (upgrade of `ScriptedFakeProvider`) | Multi-turn: one event list per `stream()` call. Full `ProviderEvent` vocabulary: `TextDelta`, `ThinkingDelta`, `ToolCall` (incl. `parse_error`, `metadata`), `ToolInputDelta`, `GroundingEvent`, `UsageEvent`, `Done(truncated)`. `raise:` step (exception class + after-N-events). Records `stream_calls`, `stream_messages`, `stream_tools`, `stream_models`, `count_input_tokens` calls, call hints. **Strict mode default**: a call past the end of the script fails the test instead of yielding nothing (today an under-scripted loop looks like an empty completion). Lives in `src/` so the gateway can build it from `MODEL_PROVIDER=fake` + `MONKEYBOT_FAKE_PROVIDER_SCRIPT=<path>`. |
| `FakeHistory` | `testkit/history.py` | Full `HistoryStore`: `load`, `append`, `append_with_outbox`, `reset`, `delete_rows`, `last_row`, `list_threads`. Optional preload (for broken-history repair scenarios). |
| `RecordingExecutor` | `testkit/executors.py` | Records calls. Returns **scripted envelopes** per tool (so `tool_error_codes` works without a real workspace). Optional `running_background_jobs()` schedule. |
| Inspectors | `testkit/inspectors.py` | `Allow`, `Deny`, `Confirm`, `OrderRecording`; real inspectors loaded from fixture configs when a scenario sets `policy:`. |
| `PresetPendingBus` | `testkit/pending_bus.py` | Pre-seeded answers for tool confirmations, `ask_user`, elicitations; or "never answer" for timeout cases. |
| `NoMCP`, `mem_sub`, `make_memory_subsystem` | `testkit/mcp.py`, `testkit/memory.py` | Moved out of `test_core_tool_executor.py` and `tests/core/memory/helpers.py`; the old call sites import from `testkit`. |
| `FakeClock` | `testkit/clock.py` | Injected into `run_scheduler_loop` / `list_due`, background-summary scheduling, stale-claim windows. Needs a small seam in `src/` (`now_ms` parameter). |
| `ScriptedClassifier` | `testkit/verifier.py` | Implements `ClassifierPort`; YAML gives intent + constraints per human row. Keeps the verifier ledger off any LLM. |
| `ScriptedJudge` | `testkit/verifier.py` | Returns fixed judge completions (valid, malformed, timeout) to `ProviderJudge`. |
| Fake subagent worker | `testkit/subagent_worker.py` (tapes in `regression/fixtures/subagent_tapes/`) | Reads a scripted NDJSON tape from the envelope; can hang, exit non-zero, print a > 64 KiB line, try to call `task`. Pointed at via `MONKEYBOT_SUBAGENT_SCRIPT`. |
| `FakeWebSearchBackend` | `testkit/web_search.py` | Fixed results; records queries. |
| `InMemoryPalace` | `testkit/palace.py` | Moved (`git mv`) from `tests/core/memory/in_memory_palace.py`. |
| Gateway harness | `testkit/gateway.py` + `testkit/sse.py` (driven by `regression/drivers/gateway.py`) | `create_app` + `LifespanManager` + scripted provider + temp agent root. **Streaming SSE reader** that parses `id:`/`data:`/comment frames and stops at a predicate (today's `httpx.AsyncClient(ASGITransport)` buffers until the response ends, so `GET /events` cannot be read in-process). |
| `open_backend(kind)` | `testkit/backends.py` (exposed as a fixture by `tests/contracts/conftest.py`) | One fixture for `sqlite` (always), `postgres` (`MONKEYBOT_TEST_POSTGRES_URL`), `firestore` (`FIRESTORE_EMULATOR_HOST`). Same skip messages everywhere. |
